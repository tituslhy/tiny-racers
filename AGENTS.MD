# Tiny Racers

Tiny Racers is a simple offline-first racing game for children aged 3 and 5.

The game must work entirely offline on an iPad during flights.

This is not a technical experimentation project.

The goal is to build a genuinely fun game for young children.

---

## Product Principles

Always prioritize:

- Fun within 5 seconds
- Very simple controls
- Bright colorful visuals
- No losing
- No frustrating mechanics
- Races must finish so children can take turns

Children should understand immediately:

"I move the car left and right."

---

## Technical Stack

Use:

- Vite
- TypeScript
- Phaser
- vite-plugin-pwa
- localStorage
- Web Audio API

---

## Constraints

Do not build:

- backend APIs
- databases
- analytics
- cloud services
- multiplayer
- distributed systems

Frontend only.

---

## Coding Philosophy

Keep code simple.

Avoid abstractions unless necessary.

Avoid unnecessary dependencies.

If the code starts resembling enterprise software:

Stop and simplify.

---

## User Experience Rules

Remember:

The end users are ages 3 and 5.

Prioritize:

- big touch targets
- simple interactions
- immediate visual feedback
- funny sounds
- joyful animations

If a feature may confuse a 3-year-old:

Do not build it.
